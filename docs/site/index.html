Ashley

A grid research environment for medical students: one wizard sets up the laptop for the university HPC grid and keeps a Claude Code worker running there, on the student's own Claude subscription, reachable from VS Code and from the Claude app on a phone.

Licensed software. Ashley is licensed, not sold: you receive a license to use it under the Ashley Software License Agreement and the Privacy Statement, accepted in a signing dialog before first use. A free Trial Edition for Wayne State AccessIDs the lab has approved, ends by itself; nothing converts to a paid license and no payment details are taken for a trial. Paid keys, when offered, are one-time term licenses and do not renew. Access is by approval: ask for access with your AccessID. Support and notices.

What Ashley accesses and does

  • Sign-ins through VS Code's own providers: your institutional Microsoft account (to check that your license names you) and GitHub (a token with the scopes repo, workflow, read:org, gist). Ashley never sees passwords.
  • Tokens: your GitHub token, your Hugging Face token and an optional Anthropic Console key are kept in the operating system's credential store and, with your consent in each wizard step, copied over SSH into a file readable only by you in your own grid account.
  • No Claude credential: Ashley never reads, stores or copies one. You sign in to Claude Code yourself, on the laptop and once in a terminal on the grid.
  • Terminals, SSH and Slurm: a managed block in ~/.ssh/config, an SSH key, terminals that run ssh to your grid account, scripts installed there, and Slurm jobs in your account (a persistent worker running the unmodified Claude Code binary; Remote Control for your phone if you turn it on).
  • MCP: an MCP server registered with the Claude Code extension, so the Claude on your laptop can hand work to the worker.
  • License check: offline verification of your key; a daily fetch of a signed list of withdrawn keys if your lab configures one; a trial request sends the licence service the Microsoft sign-in token VS Code holds so it can ask Microsoft who you are.
  • Error reports, opt-out: when a check fails, and only if you allow it, VS Code telemetry is on and a report address is configured: versions, which checks failed and their messages with names, paths and secrets replaced. Never prompts, files, tokens or your AccessID. Kept 365 days; a copy stays on your laptop.
  • No downloaded code. Everything Ashley runs ships inside the package.

Outside dependencies

Ashley works only while your institution's grid, network and account, Anthropic's services and terms, Microsoft's VS Code and Marketplace, and GitHub's and Hugging Face's services allow what it does. Any of them can stop it working; section 7 of the agreement names each, and that is not refunded (a long outage extends a paid license). Ashley is a research and teaching tool, not a medical device, and is not provided by or on behalf of any university. Ashley runs Claude Code; it is not an Anthropic product.
